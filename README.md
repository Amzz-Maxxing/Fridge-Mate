# Fridge Mate · by ShelfLife

**Fridge Mate** is a mobile app that helps households in Malaysia waste less
food and spend less: it tracks what's in the fridge, reminds you before food
expires, suggests meals that use expiring food first, and builds a smart
grocery list. It was built for the TEB2083 Technopreneurship project
(Group 22, ShelfLife).

## Features

- 📷 AI fridge and receipt scanning (Google Gemini)
- ⏰ Expiry reminders with recipe tips
- 🍳 116 recipes with expiry-first suggestions, filters, favourites and AI meal ideas
- 📅 Weekly meal planner with auto-plan and one-tap weekly shopping
- 🛒 Smart grocery list, saved lists and shopping history
- 🌗 Light and dark themes

## Tech

Flutter (Android & iOS) · Firebase Authentication · Cloud Firestore ·
Firebase AI Logic (Gemini) · on-device notifications.
